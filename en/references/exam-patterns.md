# Exam Pattern Analysis Guide

Cross-disciplinary, cross-exam-type methodology for analyzing past papers.

## Exam Type Quick Reference

| Exam Type | Typical Structure | Core Strategy |
|-----------|-------------------|---------------|
| University Final | MCQ + Fill + Short + Essay | Focus high-frequency chapters, memorize scoring templates |
| Grad School Entrance | Term def + Short + Essay + Calculation | Depth + breadth, academic expression |
| Professional Cert | MCQ + Case analysis | Question bank drilling + precise memory |
| Civil Service | Aptitude test + Essay | Speed training + document format |
| Competition | Comprehensive + Experimental design | Cross-chapter synthesis + frontier literature |
| Technical Interview | Algorithms + System design + Concepts | Oral derivation + boundary conditions |

## Step 1: Read All Papers and Answers

- Read ALL papers and ALL answer keys
- Note course name, question structure, point distribution
- Record which chapters each question targets
- Pay attention to model answer depth and format

## Step 2: Question Type Distribution

| Question Type | Points | Typical Count | What to Extract |
|---------------|--------|---------------|-----------------|
| Single-choice | 1 pt | 20 | Key facts, definitions, distinguishing features |
| True/False + correction | 2 pt | 10 | Common traps, absolute words, subtle errors |
| Term definition | 4-5 pt | 3-5 | Precise definitions with multiple dimensions |
| Short answer | 5 pt | 3-4 | Structured comparison or process |
| Essay/Discussion | 10 pt | 2 | Multi-point answer templates |
| Calculation | 10 pt | 2-3 | Formula + steps + units + verification |

Calculate chapter coverage percentage. High-frequency = must-know.

## Step 3: Extract Question Patterns

### Essay Questions — Universal 10-Point Template

Most common: "Describe the [topic] of [region/unit], with examples"

**Universal scoring dimensions** (adjust per subject):

| # | Dimension | Points | Content |
|---|-----------|--------|---------|
| 1 | Location/scope | 1 | Geographic or conceptual boundaries |
| 2 | Climate/Context | 1 | Environmental or historical background |
| 3 | Terrain/Structure | 1 | Physical or logical organization |
| 4 | Main type A + examples | 1-2 | Primary category with representative instances |
| 5 | Main type B + examples | 1-2 | Secondary category |
| 6 | Secondary/degraded | 1 | Sub-types or exceptions |
| 7 | Rare/special features | 1 | Unique or endemic elements |
| 8 | Economic/practical value | 1 | Applications or uses |
| 9 | Management/practice | 1 | Operational or maintenance aspects |
| 10 | Summary characteristics | 1 | Key takeaway or synthesis |

**Universal Mnemonic**: **"位气垂，主次更，经引特"** (Wei-Qi-Chui, Zhu-Ci-Geng, Jing-Yin-Te)

| Character | Meaning | Typical Points |
|-----------|---------|----------------|
| 位 (Wei) | Location/scope | 1 pt |
| 气 (Qi) | Climate/Context | 1 pt |
| 垂 (Chui) | Vertical/Structural distribution | 1 pt |
| 主 (Zhu) | Main types | 2-3 pts |
| 次 (Ci) | Secondary types | 1 pt |
| 更 (Geng) | Management/Regeneration | 1 pt |
| 经 (Jing) | Economic value | 1 pt |
| 引 (Yin) | Introduced/Applied | 1 pt |
| 特 (Te) | Special/Endemic features | 1 pt |

Note: Writing any 1 representative example is usually sufficient for each category point.

### True/False Questions

High-probability error patterns:
- **Absolute words**: "all", "only", "exclusively", "must" — often WRONG
- **Common confusions**: Similar terms swapped
- **Geographic errors**: Distribution ranges, origin locations
- **Taxonomic errors**: Family/genus assignments
- **Sign errors**: Positive/negative, direction

Scoring: Correct judgment (1 pt) + Accurate correction (1 pt)

### Short Answer Questions

Typical patterns:
- Compare two groups (list differences, give examples)
- Describe process or classification system
- Explain relationship between factors

Structure: Numbered/bulleted format with clear parallelism.

### Multiple Choice

Focus areas:
- Distinguishing features of similar concepts
- Geographic or logical distribution
- Economic uses and practical roles
- Classification clues

## Step 5: Create Predictions

1. **Gap-filling**: High textbook coverage but untested for 3+ years
2. **Adjacency**: Tested A last year, likely to test contrasting B this year
3. **Anniversary**: Integer-year anniversary related topics
4. **Frontier**: New textbook editions, recent 2-year hot topics
5. **Symmetry**: Exam structure tends to balance; if upper volume was heavy, lower volume may be tested more

Identify high-importance untested topics and create 2-3 prediction questions with full templates.
