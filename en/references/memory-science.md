# Memory Science for Exam Prep

Integrating cognitive science principles into review material generation.

## 1. Spaced Repetition

Ebbinghaus forgetting curve:

| Interval | Retention | Action |
|----------|-----------|--------|
| Immediate | 100% | First active recall test |
| 1 day | 44% | First formal review |
| 2 days | 36% | Second review |
| 6 days | 33% | Third review |
| 31 days | 28% | Fourth review |

Rule: New cards ≤ 20/day, review cards ≤ 100/day.

## 2. Active Recall

Passive re-reading is the least effective study method. **Close the book, write answers on blank paper.**

Good vs bad flashcards:
- ❌ Bad: "Photosynthesis" → answer too long
- ✅ Good: "What step in the Calvin cycle uses the ATP and NADPH produced in the light reactions?" → precise

Cloze format:
```
In the Calvin cycle, {{c1:CO₂}} first combines with {{c2:RuBP}} to form {{c3:2 molecules of PGA}}.
```

## 3. Elaborative Interrogation

Ask "why" for every fact:

Fact: Tree rings are more obvious in temperate zones.
Question: Why?
Answer: Temperate zones have distinct seasons, causing seasonal cambium activity variation; tropical zones have small temperature differences, so cambium activity continues year-round.

Rule: Insert 1 "why" question for every 5 facts.

## 4. Chunking

When lists have > 4 items, provide grouping or mnemonics:

Raw: Pinaceae, Taxodiaceae, Cupressaceae, Araucariaceae, Podocarpaceae
Chunked: "松杉柏，南罗" (5 families in 6 characters)
+ Feature rhyme: "Pines/firs needle/linear leaves; cypress scale/needle alternate; Araucaria/Podocarp broad leaves"

## 5. Interleaving

Don't drill the same question type continuously:

❌ Bad: 20 derivatives → 20 integrals
✅ Good: Derivative 2 → Integral 2 → Differential equation 2 → Derivative 2 → ...

## 6. Dual Coding

Activate both verbal and visual memory simultaneously:
- Text + diagram/table
- Concept + analogy ("mitochondria are the cell's power plant")
- Formula + derivation flowchart

## 7. Feynman Technique

Self-check: Can you explain it simply to a freshman?

Add at the end of each chapter:
```markdown
## Feynman Self-Check: Explain [Concept] to a Freshman
In no more than 3 sentences, avoiding jargon.
Your explanation: ________________
```

## 8. Testing Effect

Retrieving memory strengthens it. Testing content should be ≥ 30%:
- Immediate test: 3 MCQs after each small section
- Chapter test: 10 mixed questions per chapter
- Full book test: Mock exam
