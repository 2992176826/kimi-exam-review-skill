# 跨学科适配指南

按学科自动调整分析框架和输出结构。

## STEM（理工农）

### 知识组织
- **公式定理库**：原始表达式 + 适用条件 + 符号含义 + 推导概要 + 常见变体 + 易错警示
- **实验方法卡**：目的→原理→器材→步骤→注意事项→误差→数据处理
- **计算题模型**：模型名→适用条件→核心公式→典型变式→易错点

### 题型特征
- **选择题**：概念辨析 + 快速估算 + 极限/特例验证
- **填空题**：精确术语、单位、符号、正负号
- **计算题**：必须展示"设→列→解→验→答"五步
- **证明题**：从结论倒推，寻找中间引理

### 输出偏好
1. 推导过程完整（不能跳步）
2. 单位换算表（附在封面后）
3. 公式速查表（单页 A4）
4. 错题归因标签（计算/概念/审题/公式）

### 生物/农学特殊处理
- 拉丁学名斜体，属名首字母大写
- 分类检索表用 dichotomous key 结构
- 生理指标标注正常范围、测定方法、单位
- 分子实验注明试剂浓度、温度、时间

## 文科（文史哲法教）

### 知识组织
- **时间轴卡**：时期→背景→代表人物→核心主张→代表作品→历史意义→前后关系
- **概念辨析矩阵**：维度 vs 概念 A vs 概念 B
- **论述题论据库**：经典论据 + 史实论据 + 现实论据（各 3 个）

### 题型特征
- **名词解释**："定义 + 提出者 + 核心内容 + 意义" 四段式
- **简答题**：总起句 + 分点（①②③） + 总结句，每点"观点 + 例子"
- **论述题**："总-分-总"，分论点用"首先/其次/再次/最后"
- **材料分析**：引述材料 → 理论对接 → 分析评价

### 输出偏好
1. 学术化表达，使用学科术语
2. 逻辑连接词（首先/其次/由此可见/综上所述）
3. 引文格式：人名（年代）或脚注
4. 史论结合：每个观点有材料支撑

### 特殊处理
- **法学**：法条原文 + 司法解释 + 典型案例
- **教育**：理论家 + 实验 + 现实应用
- **新闻**：5W1H + 传播学理论嫁接

## 医学

### 知识组织
- **疾病卡片**：名称→定义→病因→病理→临床表现→辅检→诊断标准→鉴别诊断→治疗→预后→预防→口诀
- **药物卡片**：名称→分类→机制→适应症→禁忌症→不良反应→解毒剂→相互作用→特殊人群→记忆锚点
- **解剖记忆**：三维定位 + 功能联系（血供→静脉→神经）+ 临床挂钩

### 题型特征
- **A 型题**：注意"首选"、"最常见"、"最特异"
- **病例串题**：诊断→依据→进一步检查→治疗
- **记忆密集型**：药物=机制→适应症→禁忌→副作用→解毒剂

### 输出偏好
1. 对比表格：正常 vs 异常，疾病 A vs B
2. 流程图：诊断流程、治疗决策树
3. 口诀：解剖结构、药物分类、疾病分型
4. 病例分析模板：主诉→现病史→查体→辅检→诊断→治疗

### 特殊处理
- 正常值标注单位和性别/年龄差异
- 英文术语首次出现附英文，后续可缩写
- 影像/心电图用文字描述特征

## 编程/技术

### 知识组织
- **算法卡片**：名称→类型→思想→模板代码→复杂度→适用场景→不适用→例题→易错→变形
- **八股文卡**：概念→定义→通俗解释→核心机制→应用场景→优缺点→对比→版本→面试题
- **系统设计速查**：QPS→存储→表结构→缓存→分片→一致性→降级

### 题型特征
- **算法题**：暴力解→优化→最优解，分析时空复杂度
- **八股文**：是什么→为什么→怎么做→优缺点→应用场景→版本差异
- **系统设计**：4S 法（Scenario→Service→Storage→Scale）

### 输出偏好
1. 可运行代码 + 测试用例（正常+边界+极端）
2. 复杂度表格
3. 流程图、状态转移图、内存布局图

### 特殊处理：考证类
- 客观题：精准记忆官方定义
- 案例分析：问题识别→原因→方案→预防
- 配置题：命令准确，注意模式（用户/特权/配置）
