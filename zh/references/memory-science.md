# 记忆科学与高效学习法

将认知科学原理整合到复习资料生成中。

## 1. 间隔重复

艾宾浩斯遗忘曲线：

| 复习间隔 | 记忆保留率 | 操作 |
|----------|------------|------|
| 学完立即 | 100% | 首次主动回忆测试 |
| 1 天后 | 44% | 第一次正式复习 |
| 2 天后 | 36% | 第二次复习 |
| 6 天后 | 33% | 第三次复习 |
| 31 天后 | 28% | 第四次复习 |

规则：每天新卡片 ≤ 20 张，复习卡片 ≤ 100 张。

## 2. 主动回忆

被动重读是最低效的学习方式。要求**合上书，白纸写出答案**。

好卡片 vs 坏卡片：
- ❌ 坏："光合作用" → 答案太长
- ✅ 好："光合作用光反应产生的 ATP 和 NADPH 用于暗反应的哪一步？" → 精准

挖空格式：
```
光合作用的暗反应中，{{c1:CO₂}} 首先与 {{c2:RuBP}} 结合生成 {{c3:2分子PGA}}。
```

## 3. 精细化提问

对每个事实追问"为什么"：

事实：树木年轮在温带更明显。
追问：为什么？
答案：温带四季分明，形成层活动季节性变化大；热带温差小，形成层持续活动。

规则：每 5 个事实插入 1 个"为什么"。

## 4. 组块化

列表 > 4 项时，必须提供分组或口诀：

原始：松科 杉科 柏科 南洋杉科 罗汉松科
组块："松杉柏，南罗"（5 科 6 字）
+ 特征口诀："松杉叶针条形，柏鳞刺交互，南洋罗汉叶宽"

## 5. 交错练习

不要连续刷同一题型：

❌ 差：20 道求导 → 20 道积分
✅ 好：求导 2 → 积分 2 → 微分方程 2 → 求导 2 → ...

## 6. 双编码

同时激活语言和视觉记忆：
- 文字 + 简图/表格
- 概念 + 类比（"线粒体是细胞的发电厂"）
- 公式 + 推导过程图

## 7. 费曼技巧

自检：能否用简单语言向大一新生讲清楚？

每章末尾添加：
```markdown
## 费曼自检：向新生解释 [概念]
用不超过 3 句话解释，避免术语。
你的解释：________________
```

## 8. 测试效应

提取记忆本身就是在加强记忆。测试内容占比 ≥ 30%：
- 即学即测：学完一小节，立即 3 道选择题
- 章节测：每章结束 10 道混合题
- 全书测：模拟卷
