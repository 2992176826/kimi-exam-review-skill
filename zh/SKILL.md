# 通用考试复习技能（中文版）

## 核心原则

1. **模式驱动**：先分析真题模式，再生成资料。每个章节必须回答："这个考点在考试中怎么考？"
2. **学科优先**：先识别 STEM / 文科 / 医学 / 编程 / 语言，再调用对应框架。
3. **主动回忆**：每份输出都包含自测元素（挖空、问答、模拟题）。
4. **多格式输出**：HTML 打印 PDF / Anki 卡片 / Markdown 笔记 / JSON 题库。
5. **记忆科学**：间隔重复、组块化、精细化提问、记忆口诀。

## 工作流

### 阶段 0：上下文识别

询问或推断：
- **学科**：STEM（理/工/农）/ 文科（文/史/哲/法）/ 医学 / 语言 / 编程 / 混合
- **考试类型**：期末考 / 考研 / 考证 / 竞赛 / 面试 / 自学
- **材料**：教材？试卷？课件？大纲？
- **输出格式**：打印 PDF / Anki / Markdown / JSON / 纯文本
- **时间预算**：还剩多少天？

加载 `references/cross-subject-adaptation.md` 中对应的学科框架。

### 阶段 1：材料摄入

1. 按页码顺序读取所有上传的教材内容（图片、PDF、文本）
2. 读取所有试卷和答案解析
3. 若无试卷：根据大纲权重和教材重点生成"合成模式"
4. 构建**知识图谱**：概念 → 前置知识 → 考试频率 → 题型

### 阶段 2：模式分析

读取 `references/exam-patterns.md`。关键任务：

- **题型结构表**：各题型数量、分值、建议用时
- **章节热力图**：哪些章节分值占比高？
- **错误模式提取**：哪些陷阱重复出现？
- **得分维度拆解**：论述题几分 = 几个维度？
- **难度曲线**：易(60%) / 中(30%) / 难(10%)

### 阶段 3：内容生成（结合记忆科学）

读取 `references/memory-science.md`。应用以下技术：

| 技术 | 适用场景 | 输出形式 |
|------|----------|----------|
| 间隔重复 | 事实记忆 | Anki 卡片 / JSON 题库 |
| 主动回忆 | 自测 | 挖空 / 问答对 |
| 精细化提问 | 概念理解 | "为什么 X 导致 Y？" |
| 记忆口诀 | 列表、序列 | 首字母缩写 / 记忆宫殿 |
| 交错练习 | 易混淆主题 | 混合练习集 |
| 费曼技巧 | 深度理解 | "向新生解释" |

生成：
1. **核心复习文档**（学科适配结构）
2. **记忆卡片组**（Anki 或 JSON）
3. **模拟题集**（含答案和评分标准）
4. **错误陷阱集**（预测常见错误）
5. **押题预测**（高频但未考知识点）

### 阶段 4：格式导出

读取 `references/output-formats/`。询问用户格式：

- **打印 PDF**：`html-css-reference.md` → 浏览器打印
- **Anki**：`anki-flashcard.md` → 导入 Anki
- **Markdown**：`markdown-review.md` → Obsidian/Notion
- **JSON 题库**：`json-quiz.md` → 导入刷题软件

### 阶段 5：学习计划

生成间隔复习计划：
- 第 1-3 天：初次学习 + 制作卡片
- 第 4-7 天：主动回忆 + 模拟题
- 第 8-14 天：交错复习 + 错题整理
- 最后 48 小时：押题聚焦 + 口诀冲刺

## 跨学科规则

| 学科 | 核心重点 | 避免 |
|------|----------|------|
| STEM | 公式推导、单位分析、符号约定 | 无推导的纯记忆 |
| 文科 | 论证结构、证据链、史学方法 | 无分析的项目符号列表 |
| 医学 | 机制→症状→治疗→药物 | 无临床背景的孤立事实 |
| 编程 | 时空复杂度、边界条件、最佳实践 | 无解释的复制粘贴代码 |
| 语言 | 搭配、语法模式、语篇标记 | 无例句的单词表 |

## 质量检查清单

交付前验证：
- [ ] 每个事实都有出处（页码）
- [ ] 每个论述模板覆盖所有得分维度
- [ ] 每道模拟题都有明确答案和解析
- [ ] 每张卡片答案唯一、无歧义
- [ ] 错误陷阱具体，非泛泛而谈
- [ ] 输出格式符合用户要求
